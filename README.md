# GMod — Cloud ZIP Inspector

هذا المستودع يحتوي على سير عمل GitHub Actions لفحص أرشيف ZIP من رابط HTTPS داخل خادم GitHub، دون تنزيل الأرشيف إلى جهازك.

## ما الذي يفعله؟

1. يتحقق من رابط المصدر وحجم الأرشيف ودعم الاستئناف.
2. ينزّل الأرشيف داخل runner سحابي مع إعادة المحاولة واستكمال النقل عند انقطاعه أثناء المهمة.
3. ينشئ جرداً لمحتويات ZIP وشجرة ملفات.
4. يفحص الأرشيف باستخدام ClamAV بعد تحديث قواعده.
5. يفك الملفات إلى مساحة مؤقتة في runner فقط، مع حماية من Zip Slip والروابط الرمزية والأرشيفات ذات الحجم المفرط.
6. يفحص الملفات المستخرجة باستخدام ClamAV.
7. يحفظ التقارير النصية وCSV وJSON في `reports/latest/` ويرفعها إلى فرع `main`.

## التشغيل

1. افتح تبويب **Actions**.
2. اختر **Inspect remote ZIP**.
3. اضغط **Run workflow**.
4. أدخل رابط ZIP. القيمة الافتراضية هي رابط الأرشيف الذي تم اختباره.
5. اترك الحد الأقصى للحجم بعد فك الضغط عند 6 GiB ما لم تكن لديك معلومة أدق.
6. شغّل المهمة، ثم افتح سجل التشغيل أو مجلد `reports/latest/`.

## ملفات التقرير

- `summary.json`: ملخص النتيجة والحجم وعدد الملفات وحالة الفحص.
- `inventory.csv`: قائمة المسارات والأحجام ونوع الضغط وحالة الاستخراج.
- `tree.txt`: شجرة الملفات.
- `archive-scan.log`: سجل فحص ملف ZIP.
- `extracted-scan.log`: سجل فحص الملفات المستخرجة.
- `errors.txt`: الملفات التي تعذّر التعامل معها أو فحصها.

## مهم بشأن نشر ملفات اللعبة

هذا الـWorkflow لا ينسخ ملفات اللعبة أو محتويات الأرشيف إلى Git history أو إلى ملفات عامة. يخزن الملفات مؤقتاً داخل runner ويحذفها بعد الفحص، وينشر التقارير فقط. لا يجوز إعادة توزيع ملفات لعبة أو برامج طرف ثالث في مستودع عام إلا إذا كانت لديك حقوق إعادة توزيعها أو ترخيص يسمح بذلك.

## حدود تقنية

- runners القياسية على GitHub توفر 14 GB SSD؛ قد يفشل التشغيل إذا تجاوزت الملفات المساحة الفعلية المتاحة.
- GitHub يحظر ملفات Git العادية الأكبر من 100 MiB، ويضع حداً لحجم عملية push. Git LFS له حد 2 GB للملف الواحد في GitHub Free/Pro، وحصة تخزين/تنزيل محدودة. لذلك لا يفترض هذا المشروع أن 5 GB من الملفات يمكن رفعها إلى Git مباشرة.
- الملفات المشفرة، أو الأعضاء المتجاوزون للحدود، أو الملفات التي لم يستطع ClamAV فحصها تظهر في التقرير ولا تُعتبر نظيفة.
- نتيجة ClamAV النظيفة لا تضمن السلامة المطلقة.
- كل تشغيل ينشئ Runner مؤقتاً؛ لا تعتمد عليه كتخزين دائم.
